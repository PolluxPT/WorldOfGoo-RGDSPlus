SDL2_mixer 2.6.2 ARM64 with WAV and Ogg Vorbis codecs
Source archive from Debian
https://deb.debian.org/debian/pool/main/libs/libsdl2-mixer/libsdl2-mixer_2.6.2+dfsg.orig.tar.xz
The upstream source is unchanged. The Ogg codec uses bundled stb_vorbis.
Build using Zig 0.13.0 with the SDL2 2.26.5 ARM64 headers and shared library.
Set SRC to the extracted source directory, HDR to the SDL2 dev package
usr/include directory, and SDL_LIB to the directory containing native SDL2.

zig cc -target aarch64-linux-gnu.2.28 -shared -fPIC -O2 \
  -DMUSIC_WAV -DMUSIC_OGG -DOGG_USE_STB \
  -I"$HDR/SDL2" -I"$HDR/aarch64-linux-gnu" \
  -I"$SRC/include" -I"$SRC/src" -I"$SRC/src/codecs" \
  "$SRC"/src/*.c "$SRC"/src/codecs/*.c \
  -L"$SDL_LIB" -l:libSDL2-2.0.so.0 -lm \
  -Wl,-soname,libSDL2_mixer-2.0.so.0 -o libSDL2_mixer-2.0.so.0

The audio regression probe used the original game's Ogg sample and ARM64 Box64
under QEMU with dynarec enabled and native SDL2's dummy audio output. It verified
Ogg decoding, channel playback, completion notification, gain and cleanup.
