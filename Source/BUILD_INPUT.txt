World of Goo RGDS+ v1.0 input and audio bridge

zig cc -target x86_64-linux-gnu.2.28 -shared -fPIC -O2 -fno-builtin goo_rgds.c -ldl -o libgoo_rgds.so

device.py reads the measured stock evdev button mapping. The guest shim feeds
the game pointer and keyboard events. Y opens the keyboard and Start submits.
The game mixer retains a 4096-sample minimum buffer and gives nonzero hardware
volume steps an audible digital gain. The desktop test observed nonzero PCM
at volume step 1 using the actual GOG executable and SDL dummy output.
