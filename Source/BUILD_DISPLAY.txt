Build the native ARM64 display bridge with Zig 0.13.0 from this directory.

zig cc -target aarch64-linux-gnu.2.28 -shared -fPIC -O2 native_video.c -ldl -o librgds_video.so

Build the upper presenter with Wayland client headers and the ARM64 shared library.
Set WAYLAND_INCLUDE to the header directory and WAYLAND_ARM64_LIB to the
absolute path to the ARM64 libwayland-client.so.0.

zig cc -target aarch64-linux-gnu.2.28 -O2 -I"$WAYLAND_INCLUDE" wayland_mirror.c xdg-shell-protocol.c "$WAYLAND_ARM64_LIB" -o upper-presenter
